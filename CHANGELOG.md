# Changelog

All notable changes to OnionSwap are documented here.

## [1.0.0] — 2026-11-14

Initial public release.

### Added

- Swap via the Jupiter aggregator with best-route quotes, slippage settings, and a full quote breakdown (rate, price impact, minimum received, route, fees)
- Transfer of SOL and SPL tokens with token search inside the picker, MAX, live balances, review step, simulation before sending, and automatic associated token account creation
- Wallet connection for Phantom, Solflare and Backpack
- Token search with a full info card (price, market cap, FDV, liquidity, volume, holders, supply) and Solscan link
- Popular tokens board with live prices and a live price ticker
- Wallet overview card with balances and RPC failover between public Solana endpoints
- In-app documentation (overview, getting started, swap, finding tokens, transfer, networks & endpoints, safety, troubleshooting)
- New mascot logo and a dark violet theme with Jupiter-lime green accents

### Notes

- OnionSwap charges no fees and is fully non-custodial: every transaction is signed by the user's own wallet.
